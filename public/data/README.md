# Campsite data

`campsites.json` is a compact, map-ready extract of the Taiwan Tourism
Administration dataset
[Campground Information for the Whole of Taiwan](https://data.gov.tw/en/datasets/132066).

- Retrieved: 2026-07-30
- Dataset update shown by the publisher: 2026-06-03
- Publisher: Tourism Administration, Ministry of Transportation and
  Communications
- License: Open Government Data License, version 1.0
- Published update frequency: every March

The extract retains the campsite name, county, district, coordinates, address,
phone, website, compliance category, and listed regulatory issue. Records
without usable coordinates on or immediately around Taiwan were omitted. The
source dataset remains authoritative; the app links every rendered record back
to its dataset page and provides a Google Maps search using the published name
and address.
